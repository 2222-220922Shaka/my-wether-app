# 🌦️ My Weather App

A responsive web application that allows users to check the **current weather** and a **5-day forecast** for any city using real-time weather data.


---

## 🚀 Features

- 🌍 Detects and displays weather for your **current location**
- 🔍 Search weather by **city name**
- 🌡️ Shows **current temperature**, humidity, and weather conditions
- 📅 Displays a **5-day forecast**
- 📱 Responsive design for mobile and desktop

---

## 🛠️ Tech Stack

- **React**
- **JavaScript**
- **HTML & CSS**
- OpenWeatherMap API
